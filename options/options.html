Polyglots FR – demandes PTE : options

Projet communautaire, non officiel. Les réglages sont synchronisés par le navigateur (chrome.storage.sync).

Une demande est considérée comme répondue dès qu’un de ces pseudos y a commenté. Si tu vides la liste, toutes les demandes restent affichées. Pendant une file de réponse, ton propre pseudo (celui du compte connecté) est aussi reconnu. Saisis un pseudo par ligne ; le pseudo est celui de l’adresse du profil (profiles.wordpress.org/pseudo). Les Locale Managers et les General Translation Editors fr_FR sont listés sur make.wordpress.org/polyglots/teams/?locale=fr_FR ; pour les autres membres de l’équipe, demande-les sur le canal Slack #traductions.

{author} est remplacé par le pseudo wordpress.org de l’auteur de la demande. Le formulaire n’est jamais envoyé automatiquement.
